# 单元一：温度换算

## 学习目标

- 理解摄氏度（°C）与华氏度（°F）的关系
- 掌握换算公式 `F = C × 9/5 + 32`
- 能独立完成换算挑战

## 内容

气温播报里常出现两个单位：摄氏度和华氏度。它们之间不是简单的加减，而是一个**线性缩放 + 偏移**的关系。

核心公式：

> F = C × 9/5 + 32

也就是说，先把摄氏温度乘以 1.8，再加上 32。

:::checkpoint{type="predict" question="0°C 换算成华氏是多少度？" options=["0°F","32°F","9°F"] answer="32°F" feedback="水的冰点是 0°C，也是 32°F，这是个很好记的锚点。"}

我们验证一下：100°C（沸水）代入公式 → 100 × 9/5 + 32 = 212°F，正好是美国常用的沸点。

:::checkpoint{type="fill" question="请把公式补全：F = C × ___ + 32" answer="9/5" feedback="也可以写成 1.8，两者等价。"}

:::explore{title="动手试" body="如果某天预报是 25°C，你觉得穿短袖合适吗？先估算它的华氏度，再结合你所在城市的体感想一想。"}

## 小结

- 换算关系：`F = C × 9/5 + 32`
- 记忆锚点：`0°C = 32°F`，`100°C = 212°F`
