:::reveal{title="看解析：需求分析两大利器——MRP 与 EOQ"}
### ① MRP（物料需求计划）——该买多少、何时买

MRP 用 **MPS（主生产计划）+ BOM（物料清单）+ 库存报表** 推导出每种物料的需求量和时间。核心两步：

:::formula{
  title="净需求"
  expr="净需求 = 毛需求 + 已分配量 − 计划收到量(在途) − 现有库存量"
  vars=[
    {sym:"毛需求", mean:"计划要生产的总量"},
    {sym:"已分配量", mean:"已被其他订单占用的量"},
    {sym:"计划收到量", mean:"在途、将来会收到的量"},
    {sym:"现有库存量", mean:"仓库中现有的量"}
  ]
  note="MRP 的灵魂：扣库存、倒推时间，净需求才是真要买的。"
}

:::formula{
  theme="violet"
  title="需求时间"
  expr="需求时间 = 计划时间 − 提前期"
  vars=[
    {sym:"计划时间", mean:"需要满足需求的时点"},
    {sym:"提前期", mean:"从下单到到货所需的提前时间"}
  ]
  note="倒推下单日，避免产线停摆或仓库爆仓。"
}

### ② EOQ（经济订货批量）——每次买多少最经济

1915 年哈里斯提出。目标是让**订货成本 + 储存成本**之和最小：

:::formula{
  theme="mint"
  title="EOQ 总持有成本"
  expr="TC = S × (D ÷ Q) + H × (Q ÷ 2)"
  vars=[
    {sym:"TC", mean:"总持有 + 订货成本"},
    {sym:"S", mean:"单次订货成本"},
    {sym:"D", mean:"年需求量"},
    {sym:"Q", mean:"每次采购量"},
    {sym:"H", mean:"单位年持有成本"}
  ]
  note="求使 TC 最小的 Q，即经济订货批量。"
}

> 💭 **小北**："MRP 管『买多少、何时买』，EOQ 管『一次买多少』——一个管时点，一个管批量，合起来就是一份不浪费的采购计划。"
:::
