:::question{title="第二问：R² 怎么算、怎么判——0.95 能外推吗？", hint="先想：R² 是残差平方和除以总平方和吗？越接近几才可信？"}
拟合得好不好，得靠一个数判断。

:::reveal{title="看解析：R² 公式与最小二乘"}
:::formula{
  title="R²：判断趋势线靠不靠谱"
  expr="R² = 1 − SS_res / SS_tot"
  vars=[
    {sym:"SS_res", mean:"残差平方和（实际值与预测值之差的平方和）"},
    {sym:"SS_tot", mean:"总平方和（实际值与均值之差的平方和）"}
  ]
  note="取值 0~1，越接近 1 拟合越好。"
}

- R² 接近 1：散点紧贴趋势线，外推可信。
- R² 偏低：线只是"勉强穿过"，外推风险大。

**线性最小二乘**（最常用）：
`b = Σ((x−x̄)(y−ȳ)) / Σ(x−x̄)²`，`a = ȳ − b·x̄`。
:::
