挑供应商是采购里最见功力的活。报价最低的，可能交不了货、质量翻车。先想想：四把尺子分别适合什么场景？报价和成本又差在哪？

:::reveal{title="看解析：四把尺子 + TCO（总拥有成本）"}
| 方法 | 类型 | 核心逻辑 | 适合场景 |
| --- | --- | --- | --- |
| 德尔菲法 | 定性 | 多轮匿名征询专家，意见逐步收敛 | 新技术、缺历史数据、战略物资 |
| 层次分析法（AHP） | 定性+定量 | 目标→准则→方案分层，1-9 标度两两比较算权重 | 指标冲突（质量vs价格）、3-5家候选 |
| 权重法 | 定量 | 各指标打分×权重，算加权总分排序 | 候选多、要快筛的日常评估 |
| 成本分析法（TCO） | 成本导向 | 比**总拥有成本**，不是比报价 | 大宗、关键件、长期协议、设备 |

> 💭 **小北**："四把尺子，一把比一把更'算总账'。权重法最常用，TCO 最防'价格陷阱'。"

**TCO：报价≠成本**——供应商的"价格"不等于"成本"。TCO 把全生命周期成本都算进来：

:::formula{
  title="TCO 总拥有成本"
  expr="TCO = 采购价 + 物流 + 库存持有 + 质量成本 + 维护 + 处置 + 隐性成本"
  vars=[
    {sym:"采购价", mean:"供应商报价"},
    {sym:"物流", mean:"运输与仓储费用"},
    {sym:"库存持有", mean:"资金占用与仓储成本"},
    {sym:"质量成本", mean:"不良 / 返工 / 报废"},
    {sym:"维护", mean:"使用期维护支出"},
    {sym:"处置", mean:"报废处理费用"},
    {sym:"隐性成本", mean:"断供停产损失、切换成本、商誉损失等"}
  ]
  note="选 TCO 最低，而非报价最低——报价只是冰山一角。"
}

选 **TCO 最低** 的，而不是报价最低的。
