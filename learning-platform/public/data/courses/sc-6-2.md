## 一、供应链舆情：四类与四特征

> ☕ **周师傅**："舆情不是『网友闲聊』，它是供应链运行状态的『晴雨表』。先认全它。"

**按环节分四类：**

| 类型 | 关注什么 |
| --- | --- |
| **市场舆情** | 供需波动、价格变动、竞品动态 |
| **政策舆情** | 监管、进出口管制、税收环保政策 |
| **物流舆情** | 时效、运输安全、仓储、运力 |
| **供应商舆情** | 信用、履约能力、经营稳定性 |

**数字时代四个特征，记成"快、广、连、狠"：**

:::cards{
  title="数字时代四个特征，记成『快、广、连、狠』"
  theme="coral"
  items=[
    {title:"实时性", desc:"快速生成、即时传播，反映当下状态。"},
    {title:"传播性", desc:"跨地域、跨主体广覆盖。"},
    {title:"关联性", desc:"单一环节事件可联动引爆多环节。"},
    {title:"破坏性", desc:"负面舆情若没及时管，易引发断供、信任危机。"}

}

> 💭 **小北**："那条冷链差评 3 小时覆盖 20 城——『传播性 + 关联性』叠加，小火星瞬间成大火。"

## 二、多源数据：风险感知的"源头活水"

> ☕ **周师傅**："舆情数据从哪来？两大家族，各有性格。"

| 来源 | 特点 | 包含什么 |
| --- | --- | --- |
| **上下游协同数据** | 针对性强、准确、关联强 | 订单/物流/库存/生产/质检等运营核心数据；员工投诉、内控隐患等内部反馈；供应商履约、客户评价等协同交互 |
| **第三方平台数据** | 覆盖广、实时、量大 | 新闻/社交/论坛等公开舆情；政府政策公告；行业报告、市场波动；信用评级、物流风险报告 |

这些数据有四个"脾气"：

> ☕ **周师傅敲黑板**：ST 高鸿九年"空转"虚假贸易，虚增营收约 198 亿、构成欺诈发行——合同发票银行流水全"齐全"，唯独没有真实货物流转。数据再精美，缺了诚信就是精密的伪装。**采集要合法，使用要守伦理，这是底线。**

## 三、监测四步流程：采集→预处理→监测→异常识别

> ☕ **周师傅**："数据到手，怎么变成预警？走这套闭环。"

| 步骤 | 干什么 |
| --- | --- |
| **① 采集** | 多源实时/批量/定向采集，覆盖全链路 |
| **② 预处理** | 清洗 + 标准化 + 整合，提炼核心 |
| **③ 监测** | 盯三件事：**热度**（传播/转发/评论量）、**情感倾向**（正/负/中，重点跟负面）、**传播路径**（起源、节点、扩散范围） |
| **④ 异常识别** | 设阈值，抓三类异常：**热度骤升**、**负面集中**、**关联核心环节**（核心供应商/关键线路/核心产品） |

> 💭 **小北**："原来监测不是『看看有没有人骂』，而是算热度、判情感、追路径，最后用阈值卡出真正的红线。"
