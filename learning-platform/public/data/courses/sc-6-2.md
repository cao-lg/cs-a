先想想：舆情可不止"网友闲聊"，它分几类、又有什么特征，能让一条差评 3 小时烧到 20 城？

:::reveal{title="看解析：舆情四类与四特征"}
> ☕ **周师傅**："舆情不是『网友闲聊』，它是供应链运行状态的『晴雨表』。先认全它。"

**按环节分四类：**

| 类型 | 关注什么 |
| --- | --- |
| **市场舆情** | 供需波动、价格变动、竞品动态 |
| **政策舆情** | 监管、进出口管制、税收环保政策 |
| **物流舆情** | 时效、运输安全、仓储、运力 |
| **供应商舆情** | 信用、履约能力、经营稳定性 |

**数字时代四个特征，记成"快、广、连、狠"：**

:::question{title="第二问：多源舆情数据从哪来、长什么样？", hint="先猜：风险感知的『源头活水』有哪两大家族？"}
数据不是凭空来的。先凭直觉列一列：供应链舆情数据会从哪些渠道冒出来？

:::reveal{title="看解析：多源数据与预处理"}
> ☕ **周师傅**："舆情数据从哪来？两大家族，各有性格。"

| 来源 | 特点 | 包含什么 |
| --- | --- | --- |
| **上下游协同数据** | 针对性强、准确、关联强 | 订单/物流/库存/生产/质检等运营核心数据；员工投诉、内控隐患等内部反馈；供应商履约、客户评价等协同交互 |
| **第三方平台数据** | 覆盖广、实时、量大 | 新闻/社交/论坛等公开舆情；政府政策公告；行业报告、市场波动；信用评级、物流风险报告 |

这些数据有四个"脾气"：

:::cards{
  title="舆情数据有四个『脾气』"
  theme="amber"
  items=[
    {title:"异构", desc:"文本/图/数值/视频格式杂。"},
    {title:"实时", desc:"慢了就抓不住萌芽。"},
    {title:"海量", desc:"需高效筛选。"},
    {title:"碎片化", desc:"零散需整合清洗。"}

**预处理三件事：**

:::steps{

:::question{title="第三问：舆情监测的标准四步流程是什么？", hint="先想：从『采集』到『抓异常』，中间还差哪几步？"}
数据捞回来了，怎么把它变成预警？先凭直觉排出这套流程的顺序。

:::reveal{title="看解析：监测四步流程"}
> ☕ **周师傅**："数据到手，怎么变成预警？走这套闭环。"

| 步骤 | 干什么 |
| --- | --- |
| **① 采集** | 多源实时/批量/定向采集，覆盖全链路 |
| **② 预处理** | 清洗 + 标准化 + 整合，提炼核心 |
| **③ 监测** | 盯三件事：**热度**（传播/转发/评论量）、**情感倾向**（正/负/中，重点跟负面）、**传播路径**（起源、节点、扩散范围） |
| **④ 异常识别** | 设阈值，抓三类异常：**热度骤升**、**负面集中**、**关联核心环节**（核心供应商/关键线路/核心产品） |

> 💭 **小北**："原来监测不是『看看有没有人骂』，而是算热度、判情感、追路径，最后用阈值卡出真正的红线。"
:::
