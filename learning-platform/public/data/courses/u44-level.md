> 小北盯着仓库那串忽上忽下的数字：没有趋势的波动，反而最难拍板。

（小北盯着仓库那串忽上忽下的数字：没有趋势的波动，反而最难拍板。）先凭直觉答：移动平均预测，取最近几期？

:::reveal{title="看解析：移动平均法"}
用最近 N 期实际值的平均，作为下一期预测。N 越大越平滑、也越滞后。

例：最近 3 期销量 [120, 130, 140]，则下期预测 = (120+130+140)/3 = 130。
:::
:::checkpoint{type="fill" question="补全：第 t+1 期移动平均预测 = 最近 ___ 期实际值的平均" answer="N" feedback="移动平均取最近 N 期（窗口大小）求平均，N 越大越平滑、也越滞后。"}
:::

:::question{title="第二问：指数平滑法——给近期更大权重", hint="先想：预测值是不是该更听'最近一期实际'的话？"}
移动平均对所有近期一视同仁，指数平滑则给近期更大权重。

:::reveal{title="看解析：指数平滑公式与算例"}
给近期更大权重，递归平滑。**α ∈ (0,1]**，越大越看重最近一期。

:::formula{
  title="指数平滑：用加权递归抓住近期"
  expr="F_{t+1} = α · A_t + (1−α) · F_t"
  vars=[
    {sym:"F_{t+1}", mean:"下一期预测值"},
    {sym:"A_t", mean:"本期实际值"},
    {sym:"F_t", mean:"上期预测值"},
    {sym:"α", mean:"平滑系数，∈(0,1]，越大越看重近期"}
  ]
  note="本质是「上期预测」与「本期实际」的加权平均，近期被放大权重，预测更「跟手」。"
}

**算例**：设 F₁ = A₁ = 130，α = 0.5，后续实际值 [130, 140]：
- F₂ = 0.5 × 130 + 0.5 × 130 = 130
- F₃ = 0.5 × 130 + 0.5 × 140 = 135
:::
:::checkpoint{type="fill" question="补全：指数平滑预测 = α × 本期实际值 + (1−α) × ___" answer="上期预测值" feedback="指数平滑是'上一期预测'与'本期实际'的加权平均，F 代表上期预测值。"}
:::

:::question{title="第三问：怎么选 & 误差怎么看？", hint="先想：出现大促峰值，移动平均和指数平滑哪种被拉偏更狠？"}
两种水平预测法怎么挑、准不准？

:::reveal{title="看解析：选型 + 误差指标 + 局限"}
:::cards{
  title="两种方法怎么选"
  items=[
    {title:"移动平均", desc:"数据平稳、想简单 → 取最近 N 期求平均；N 越大越平滑、也越滞后。"},
    {title:"指数平滑", desc:"想自动给近期加权、无需存整段窗口 → 用 α 调节灵敏度（越大越跟手）。"}
  ]
}

- **误差指标**：用 **MAE**（平均绝对误差）或 **MAPE**（平均绝对百分比误差）比较两种方法，选误差小的那个。
- **局限**：都只适合**短期**；出现大促峰值会被拉偏，需先剔异常或叠加季节性。
:::
:::checkpoint{
  type="multiple_choice"
  scenario="销量突然来了一个大促峰值，你要选一种更扛冲击的方法。"
  question="关于两种水平预测法的局限，下列说法正确的是？"

  answer="都只适合短期，大促峰值会把它们拉偏"
  hints=["两种方法都是水平序列短期法。","峰值属于异常，会拉偏均值/加权均值。"]
  feedback="两种法都只适合短期；大促峰值属于异常，会拉偏预测，需先剔异常或叠加季节性。"
  unlock="实战中先用箱线/规则剔掉大促峰值，再做水平预测更稳。"
}
:::
