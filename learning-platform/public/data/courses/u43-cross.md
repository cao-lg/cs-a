（小北在白板上画了两个维度：光说"华东好"，可能掩盖了某品类其实在掉。）先凭直觉答：同时看"地区 × 品类"，这叫什么分析？

:::reveal{title="看解析：交叉分析 = 多维组合"}
单一维度会骗人。**交叉分析** = 把两个或更多维度叠在一起看，比如 `地区 × 品类`、`渠道 × 时段`。

- 只看"地区"：华东最好。
- 叠上"品类"：华东好，是因为空调；它的小家电其实在掉。
- 真相藏在**交叉格**里。

    {title:"堆叠柱", desc:"看分类 + 子分类的构成占比。"}
  ]
}
:::

:::question{title="第二问：交叉分析怎么选图？——"地区×品类"均值看什么图？", hint="先想：要一眼看出冷热矩阵，用哪种图？"}
选对图，交叉格里的真相才看得清。

:::reveal{title="看解析：交叉分析的选图对照"}
| 场景 | 图 |
| --- | --- |
| 二维均值 / 密度矩阵 | 热力图 |
| 分类 + 子分类 | 堆叠柱 / 分组柱 |
| 多维下钻 | 透视表 + 切片器 |
:::

:::question{title="第三问：两个必须警惕的陷阱——相关就是因果吗？", hint="先想：冰淇淋销量和溺水人数同涨，是因为冰淇淋让人溺水吗？"}
交叉分析好用，但有两个坑，新手极易踩。

:::reveal{title="看解析：相关 ≠ 因果 与 辛普森悖论"}
:::cards{
  title="两个必须警惕的陷阱"
