顾客问 20°C 适不适合坐露天位，你脑子里却是 68°F——两套温标必须先打通换算，否则面包店开不下去。

:::reveal{title="看解析：摄氏 ↔ 华氏 换算公式"}
:::formula{
  title="摄氏 ↔ 华氏 换算公式"
  expr="F = C × 9/5 + 32"
  vars=[
    {sym:"F", mean:"华氏度（°F），火星烤箱用的温标"},
    {sym:"C", mean:"摄氏度（°C），火星温度计显示的温标"},
    {sym:"9/5（即 1.8）", mean:"刻度比例：摄氏 100 格（0→100）对应华氏 180 格（32→212），所以 1°C = 1.8°F"},
    {sym:"+32", mean:"冰点偏移量：两个温标起点不同（0°C = 32°F），所以要加 32"}
  ]
  note="记忆锚点：0°C = 32°F（冰点）、100°C = 212°F（沸点）。"
}
换句话说：先把摄氏温度乘以 1.8，再加上 32。

:::question{title="第二问：公式为什么是 ×1.8 + 32？", hint="先想：两个温标的刻度大小一样吗？起点一样吗？"}
为什么公式是 `× 1.8 + 32`？先凭直觉猜：摄氏 100 格对应华氏多少格？

:::reveal{title="看解析：刻度比例 + 冰点偏移"}
因为两个温标的"刻度大小"不一样：摄氏 100 格（0→100）对应华氏 180 格（32→212），所以 1°C = 1.8°F。再加上 32 的偏移量，是因为冰点起点不同。
:::

:::question{title="第三问：实战——烤一只火星可颂该设多少度？", hint="先动手算：把 25°C 代入公式，等于多少 °F？"}
可颂面团第一次发酵需要 25°C。你的烤箱按钮全是华氏度，该设多少？

:::reveal{title="看解析：代入换算，取整"}
把 C = 25 代入：F = 25 × 1.8 + 32 = 77°F。可颂的发酵温度一般在 75–80°F 之间，77°F 刚刚好。

再练一个：火星港口今天 38°C，体感多少 °F？38 × 1.8 + 32 = 100.4°F——这就是 38°C 让人喘不过气的原因；而 38°F 约等于 3.3°C，那是冷藏室温度，两个温标的数字不能直接比较。
:::
