## 学习目标

- 理解摄氏度（°C）与华氏度（°F）的换算关系
- 记住两个锚点：冰点 0°C = 32°F，沸点 100°C = 212°F
- 能在生活场景（烘焙、天气）中快速换算

> **F = C × 9/5 + 32**

换句话说：先把摄氏温度乘以 1.8，再加上 32。

## 公式拆解

为什么公式是 `× 1.8 + 32`？

因为两个温标的"刻度大小"不一样：摄氏 100 格（0→100）对应华氏 180 格（32→212），所以 1°C = 1.8°F。再加上 32 的偏移量，是因为冰点起点不同。

:::checkpoint{
  type="fill"
  scenario="你的笔记本被火星风吹走了，只剩下半页公式。"
  question="补全公式：F = C × ___ + 32"
  answer="9/5"
  hints=["1.8 和 9/5 是同一个数。"," Celsius 100 格对应 Fahrenheit 180 格，比例是多少？"]
  feedback="9/5 = 1.8。公式也可以写成 F = C × 1.8 + 32。"
  unlock="分数形式 9/5 更精确，不容易在口算时四舍五入丢精度。"
}

## 小结

- 换算关系：`F = C × 9/5 + 32`
- 记忆锚点：`0°C = 32°F`，`100°C = 212°F`
- 火星烘焙口诀："乘 1.8，加 32，发酵不翻车"
