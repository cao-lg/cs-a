:::reveal{title="看解析：国标 GB/T 23050-2022 的四个流"}

:::question{title="第四问：怎么落地？靠『五大视图』", hint="先想：战略、角色、业务、数据、技术，谁指挥谁？"}
企业常犯五个错：只关注技术、只关注业务、战略缺失、角色缺失、数据缺失。先凭直觉答：五大视图里，谁指挥角色、谁执行业务？

要系统落地，国标给出**五大视图**，缺一不可——战略指挥角色，角色执行业务，业务产生数据、提出技术需求，技术又反过来支撑业务：

| 视图 | 面向谁 | 核心焦点 |
| --- | --- | --- |
| 战略视图 | 决策层 | 战略方向、目标与绩效指标 |
| 角色/组织视图 | 决策层+管理层 | 涉及哪些主体、谁负责 |
| 业务视图 | 管理层 | 主要业务活动（计划/采购/生产/交付/服务） |
| 数据视图 | 平台开发商 | 数据资源的开发利用过程 |
| 技术视图 | 平台开发商 | 所需关键技术 |

:::question{title="第五问：不同产品，该配哪种供应链？", hint="先想：牙膏和动漫手办，能用同一种打法吗？"}
1997 年费舍尔说：没有一种策略适合所有企业。先凭直觉答：大米该配效率型，还是响应型？

:::reveal{title="看解析：产品属性决定供应链打法（效率型 vs 响应型）"}
产品属性决定供应链打法。先把产品分两类，再各配一种供应链：

| 类型 | 边际收益 | 需求特征 | 生命周期 | 例子 |
| --- | --- | --- | --- | --- |
| 功能型产品 | 较低 | 稳定、可预测 | 长 | 牙膏、纸巾、大米 |
| 创新型产品 | 较高 | 个性化、难预测 | 短 | 动漫手办、新款手机、奢侈品墨镜 |

对应两种供应链，配对逻辑就一句——稳定需求配效率，不确定需求配响应：

:::cards{
  title="没有一种策略适合所有企业：两种供应链"
  theme="mint"
  items=[
    {title:"效率型供应链", desc:"追求总成本最低，适合功能型产品（稳定需求、激烈竞争）。"},
    {title:"响应型供应链", desc:"追求快速反应，适合创新型产品（需求不确定、要新颖）。"}
  ]
}

**两个活标本**——同样是卖衣服，一个拼效率、一个拼速度：

:::compare{
  left={title:"优衣库 · 拼效率", desc:"基础款（HEATTECH、UT），需求稳、可预测，数字化始终围绕『极致效率』。", points:["AI 精准预测", "RFID 单品级库存", "与东丽数据共享"]}
  right={title:"ZARA · 拼速度", desc:"快时尚，生命周期短、高度不确定，数字化聚焦『极速响应』。", points:["门店 POS 实时上传", "2~3 周设计到上架", "西班牙周边柔性工厂、全球 48 小时到货"]}
}

**推-拉结合**：现实里很少有纯效率或纯响应的供应链，大多是"推动-拉动"组合。上游靠预测**推动**生产，面向市场一端靠需求**拉动**响应；两者的分界点叫 **CODP（推-拉分界点）**。ZARA 的 IDS 系统，核心能力就是**动态调节这个分界点**——旺季前移保稳定，流行期后移提敏捷，把设计到上架压到 2~3 周。
:::

:::question{title="最后一问：转正小考——数据怎么反过来『拉』着生产跑？", hint="先快速过一遍全任务，再答题"}
把「买了系统≠数字化 → 四个流 → 四大原则 → 五大视图 → 产品配策略」串成一张网——下面这道综合题，考你这个任务到底学没学透。

:::reveal{title="考前锦囊：一张图回顾全任务"}
> 回顾主线：**数字化转型本质=业务/模式/价值重构（非仅工具）→ 国标四个流（业务·资金·物流·数据流，数据流是灵魂）→ 四大原则（数据驱动为总开关）→ 五大视图整体闭环 → 费舍尔匹配（功能型配效率型、创新型配响应型，CODP 推拉分界）**。

理解了"产品配策略"，再往前一步：数据能不能**直接反过来牵引生产**？能，这就是新一代模式——把供应链"掉头"：

:::cards{
  title="数据反过来『拉』着生产跑：两种新模型"
  theme="violet"
  items=[
    {title:"C2M（Customer To Manufacturer）", desc:"平台跳过品牌商、经销商等所有中间环节，直接连消费者和工厂，消费者拿工厂价买定制/高性价比产品。代表：必要商城、拼多多『农地云拼』、海尔卡奥斯定制。"},
    {title:"C2B2M", desc:"在消费者和工厂之间加一个『B』（平台企业），由平台整合需求、驱动柔性制造。即『消费者聚集平台 + 柔性制造工厂』。代表：拼多多新品牌计划、小米生态链、SHEIN。"}
  ]
}

> ☕ **周师傅讲个案例**：拼多多的"农地云拼"，用数字平台把分散的消费者和农田直连，把零散需求聚成"云端订单"，变"推动式"为"拉动式"，直接驱动产地种植——本质是 C2M 在农业的落地。它不只帮农民卖货，还吸引了"新农人"返乡，重构了整个产业组织。
:::
