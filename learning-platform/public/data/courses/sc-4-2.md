某环保材料制造企业，要消化一批**未完成客户订单**。先凭直觉看看，手排为啥排不动？

:::reveal{title="看解析：约束会互相打架，经验调度本质是『瞎试』"}
硬约束就这几条：

| 约束类别 | 具体内容 |
| --- | --- |
| **设备** | 完成以上产品的全工序自动化设备，**共 3 台** |
| **人员** | 操作人员 **2 人** |
| **工时** | 每天工作 **8 小时** |
| **标准工时** | 每种产品每件所需的加工时间（各不相同） |
| **交付周期** | 从工厂到各客户仓库的运输天数（各不相同） |

小北和同学们分组研讨时发现：排产要考虑的约束会**互相打架**——设备只有 3 台，可订单要的产能可能远超；人只有 2 个，可工序要的人可能更多；交期紧的订单，还得算上运输天数倒推开工时间。

> 💭 **小北**："我试着手排，排到第三张单就乱了——这台设备到底先给谁用？早开工的万一占着设备，急单又进不来……"

各小组把讨论结果输进 AI 智能体，点"执行排产"，系统立刻**提示约束失败**，并标出冲突点。老师借机点题：**靠经验人工调度，本质是『在局部里瞎试』；数据驱动的智能排程，是把问题变成可计算的优化模型。**

:::question{title="第二问：智能排程的闭环，长啥样？", hint="先想：智能排程是不是按个按钮就出答案？"}
有人以为智能排程就是"一键出结果"。先凭直觉说说，它背后是一套什么机制？

:::reveal{title="看解析：智能排程的『感知—决策—执行—学习』闭环"}
数据驱动的智能排程，以数据为核心、算法为引擎、平台为支撑，构建了全流程自适应的闭环：

| 环节 | 在排产里做什么 |
| --- | --- |
| **感知** | 实时采订单、产能、物料、工时，打通 ERP/MES/WMS 接口 |
| **决策** | 把约束翻译成数学模型，算法在可行域里寻优（成本最低或产量最高） |
| **执行** | 下发排产指令到设备与产线，滚动调整 |
| **学习** | 用实际结果反哺模型，下次排得更准 |

:::question{title="第三问：规划求解，怎么把现实翻译成数学？", hint="先想：一道排产题，逃不开哪三块『积木』？"}
周师傅说规划求解就三块积木。先凭直觉列出：把现实翻译成数学，必须说清哪三件事？

:::reveal{title="看解析：规划求解的三要素"}
任何一道排产优化题，都逃不开这三个基本要素：

| 要素 | 是什么 | 记号 / 形式 |
| --- | --- | --- |
| **决策变量** | 你可以控制、要解的"未知数" | 第 j 个变量记为 xⱼ，整体 X=(x₁,x₂,…,xₙ) |
| **目标函数** | 衡量方案好坏的尺子（要最大或最小） | Max/Min Z = c₁x₁+c₂x₂+…+cₙxₙ |
| **约束条件** | 变量必须满足的现实限制 | 资源≤、需求≥、平衡=、非负/整数 |

**约束长什么样？** 现实限制主要分四类——

:::cards{
  theme="mint"
  title="规划求解的四类约束"
  items=[
    {title:"资源约束（≤）", desc:"消耗的资源不能超过可用上限，如 a₁₁x₁+…+a₁ₙxₙ ≤ b₁（b₁ 为第 1 种资源总量）。"},
    {title:"需求约束（≥）", desc:"产出必须满足最低需求，如 a₁₁x₁+…+a₁ₙxₙ ≥ d₁（d₁ 为最低标准）。"},
    {title:"平衡约束（=）", desc:"某些变量必须相等，如 a₁₁x₁+…+a₁ₙxₙ = b₁。"},
    {title:"非负与整数约束", desc:"xⱼ ≥ 0；若该量只能是整件/整人，还要 xⱼ ∈ Z。"}
  ]
}

> 💭 **小北**："哦——原来『这台设备先给谁』就是决策变量，『别超3台、别超8小时』就是约束，『总成本最低』就是目标函数。三块一拼，题就立起来了。"
:::

:::question{title="第四问：六道工序，怎么配人最省？", hint="先想：人手怎么组合，才能既达标又最便宜？"}
某电子厂有六道工序，可配普工、中级工、高级工三种人，单价不同、手速不同。目标就一个——在满足每道工序每小时产能的前提下，总用工成本最低。先想想怎么建模？

:::reveal{title="看解析：六道工序配人的建模"}
**已知条件（教学简化示例）：**

| 工种 | 单位工时成本 |
| --- | --- |
| 普工 | 20 元/小时 |
| 中级工 | 25 元/小时 |
| 高级工 | 30 元/小时 |

六道工序（PCBA 焊接、半成品预测、面壳装配、底壳装配、耦合测试、贴标写串码与包装）对三种工种的**工时定额**（每件所需秒数）各不相同——高级工手快但贵，普工便宜但慢。

**怎么建模？**
- **决策变量**：每道工序分别安排几名普工、中级工、高级工（共 18 个 xⱼ）。
- **目标函数**：Min 总成本 Z = Σ(工种单价 × 该工种人数 × 工时)。
- **约束**：①每道工序的实际产能 ≥ 要求的每小时产量；②总人数受车间编制限制；③人数非负且为整数。

把这张表输进规划求解，算法会在成千上万种"人手组合"里，自动挑出**既达标又最便宜**的那一组。人不再去"试排"，而是审核算法给的方案、处理例外。

> 💭 **小北**："这道题我要手算，得试到明天。但翻译成模型，电脑毫秒级就吐出最优解——而且每次插单，重算一遍就行。"
:::
