> 小北翻出去年的周报：同样涨了 10%，"比"的对象不同，讲出来的故事完全两样。

（小北翻出去年的周报：同样涨了 10%，"比"的对象不同，讲出来的故事完全两样。）先凭直觉选：和"去年同期"比，属于哪类维度？

:::reveal{title="看解析：对比分析的五维度"}
"对比"不是随便比，得先选**维度**，结论才站得住。五个常用维度：

:::cards{
  title="对比先选维度，结论才站得住"
  items=[
    {title:"时间", desc:"今年 vs 去年（同比 YoY）、本月 vs 上月（环比 MoM）。看『变了多少』。"},
    {title:"空间", desc:"华东 vs 华南、线上 vs 线下。看『哪里强』。"},
    {title:"类别", desc:"品类 A vs 品类 B、客群分层。看『结构差异』。"},
    {title:"目标", desc:"实际 vs 目标 / KPI。看『达标没』。"},
    {title:"竞争", desc:"自家 vs 竞品、vs 行业均值。看『排第几』。"}
  ]
}

> 同一组数，跟"去年"比和跟"目标"比，讲出来的故事可以完全不同——**先定维度，再下结论**。
:::
:::checkpoint{type="fill" question="补全：和“去年同期”比，属于 ___ 维度对比（时间/空间/类别）" answer="时间" feedback="同比、环比都归到时间维度。"}
:::

:::question{title="第二问：维度配什么图？——时间趋势该用哪类图？", hint="先想：要突出'变化'，用折线还是柱状？"}
选好维度，图表也得配对，否则故事讲歪。

:::reveal{title="看解析：维度 → 图表 对照表"}
| 对比维度 | 推荐图表 | 理由 |
| --- | --- | --- |
| 时间趋势 | 折线图 | 突出"变化" |
| 空间 / 类别 | 柱状图（分组） | 突出"谁大谁小" |
| 构成占比 | 饼图 / 堆叠柱 | 突出"份额" |
| 目标达成 | 子弹图 / 仪表盘 | 突出"距目标多远" |
| 竞争对标 | 分组柱 / 雷达图 | 突出"相对位置" |
:::
:::checkpoint{
  type="multiple_choice"
  scenario="你要向老板展示'今年每月销售额相对去年的变化'。"
  question="这个时间趋势对比，最适合用哪类图？"
  options=["折线图","饼图","堆叠柱","雷达图"]
  answer="折线图"
  hints=["时间趋势看'变化'。","折线图最突出变化走势。"]
  feedback="时间趋势用折线图突出"变化"；饼图看份额、雷达图看多维对标，都不适合单一时间走势。"
  unlock="维度决定故事，图表决定故事怎么被看见。"
}
:::

:::question{title="第三问：三个坑——对比时最容易被骗的地方", hint="先想：'增长100%'听起来很猛，但它可能只是从 1 到 2，你信吗？"}
对比容易踩坑，新手尤其要警惕。

:::reveal{title="看解析：对比分析的三个常见陷阱"}
:::cards{
  title="对比分析的三个常见陷阱"
  theme="mint"
  items=[
    {title:"基期陷阱", desc:"同比时去年是否含大促？口径不一致，比了也白比。"},
    {title:"百分比陷阱", desc:"『增长 100%』可能只是从 1 到 2；看绝对量。"},
    {title:"幸存者偏差", desc:"只比留下来的客户，忽略流失的。"}
  ]
}
:::
:::checkpoint{
  type="multiple_choice"
  scenario="同行说'A 产品增长 100%'，你一看发现它只是从月销 1 件涨到 2 件。"
  question="这最可能踩了哪个陷阱？"
  options=["基期陷阱","百分比陷阱","幸存者偏差","都没踩，确实翻倍"]
  answer="百分比陷阱"
  hints=["看绝对量，别被百分比吓到。","从 1 到 2 是 100%，但基数极小。"]
  feedback="这就是百分比陷阱：百分比好看，但绝对量极小，结论毫无意义。记得同时看绝对量。"
  unlock="下次看到夸张百分比，先问一句：基数是多少？"
}
:::
