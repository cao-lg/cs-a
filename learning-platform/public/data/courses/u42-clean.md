（小北把这张表截进备忘：先把离谱的数揪出来，后面才能放心做分析。）先凭直觉分一分：这些异常，属于哪类错误？

:::reveal{title="看解析：三类逻辑错误（判断标准各不同）"}
数据清洗第一步，是把"明显不对"的**逻辑错误**挑出来。它们分三类，判断标准不同：

:::cards{
  title="三类逻辑错误：判断标准各不同"
  items=[
    {title:"① 不合理（implausible）", desc:"数值落在业务不可能出现的范围。例：一笔销售金额 = -50（钱不可能为负）；年龄 = 256；转化率 = 350%。特征：单字段就能判定，不依赖别的字段。"},
    {title:"② 矛盾（contradictory）", desc:"多个字段互相打架。例：销量 = 0 但销售额 = 9999；金额为负却成交量 > 0；库存减少却无出库记录。特征：必须跨字段校验，常用 销量 × 单价 ≈ 金额 做一致性检查。"},
    {title:"③ 违规（violating rules）", desc:"违反既定业务规则或约束。例：同一订单号出现两次（重复单）；必填字段为空；日期格式非法；商品 ID 不在主数据里。特征：对照『规则清单』逐条核对，最容易被遗漏。"}
  ]
}

> 口诀：**单看离谱叫不合理，互相打架叫矛盾，违了规矩叫违规。**
:::
:::checkpoint{type="fill" question="补全：销量=0 但销售额=9999，属于 ___ 错误（不合理/矛盾/违规）" answer="矛盾" feedback="单字段看不出问题，是跨字段互相打架，所以是矛盾。"}
:::

:::question{title="第二问：清洗方法——按什么顺序最稳？", hint="先想：如果一张表同时混着重复单和离谱值，该先处理哪个？"}
三类错误认出来了，怎么动手清洗？顺序很重要。

:::reveal{title="看解析：清洗方法 + 黄金顺序"}
| 方法 | 做什么 | 适用 |
| --- | --- | --- |
| 标注 | 给行打错误类型标签，先不删 | 全部三类 |
| 去重 | 按主键删重复记录 | 违规（重单） |
| 范围校验 | 设 min/max，超界即标 | 不合理 |
| 一致性校验 | 跨字段公式核对 | 矛盾 |
| 修正 / 剔除 | 能修则修（如负号反转），不能修则置空或删 | 视情况 |

> 黄金顺序：**先去重 → 再查不合理 → 最后查矛盾与违规**。因为重复行会放大后面所有统计误差。

:::steps{
  title="清洗的黄金顺序"
  theme="mint"
  steps=[
    {title:"① 去重", desc:"按主键删重复记录。重复行会放大后面所有统计误差，所以最先做。"},
    {title:"② 查不合理", desc:"范围校验：设 min/max，超界即标（金额=-50 这类单字段离谱值）。"},
    {title:"③ 查矛盾与违规", desc:"一致性校验（销量×单价≈金额）+ 规则清单核对（重复单/空值/非法格式）。"}
  ]
}
:::

:::question{title="第三问：动手体检——这张订单表哪几行有病？", hint="先想：A003 金额为 -250，A004 出现两次，分别是什么错误？"}
给一张真实订单表"体检"，把每一行的毛病诊断出来。

:::reveal{title="看解析：订单表逐行诊断"}
| 订单号 | 销量 | 销售额 | 诊断 |
| --- | --- | --- | --- |
| A001 | 3 | 150 | 正常 |
| A002 | 0 | 9999 | 矛盾（销量为 0 却有大额） |
| A003 | 5 | -250 | 矛盾 / 不合理（金额为负） |
| A004 | 2 | 100 | 正常 |
| A004 | 2 | 100 | 违规（订单号重复） |

> 一眼体检：销量 0 却有大额是矛盾，金额为负既矛盾又不合理，订单号重复是违规。
:::
